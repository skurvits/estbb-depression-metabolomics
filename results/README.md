# Aggregate verification results

These files are non-identifying aggregate outputs retained to make the public code easy to audit against the manuscript. They are not substitutes for the journal's Supplementary Tables.

The headline results are:

- Model 1: 1,367 significant metabolite–symptom pairs
- Model 2: 660
- Model 3: 136
- 691 BMI-interaction candidate pairs
- 211 FDR-significant metabolite × BMI interactions
- 3 FDR-significant conditional metabolite × SOM-profile interactions
